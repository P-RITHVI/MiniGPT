# Evaluation

Cross entropy is the mean next-token negative log likelihood; perplexity is `exp(loss)` and is omitted if exponentiation would overflow. Validation is sampled during training and selects the saved checkpoint. `scripts/evaluate.py` computes test loss from the final contiguous split after training and compares it with an add-one-smoothed bigram baseline using the same tokenizer and splits. Scores from character and BPE tokenizations are not directly comparable. Generated text is qualitative evidence only. Measured Alice and four-book BPE runs, with fixed-seed samples and training histories, are documented in the README and the corresponding `alice_bpe_*` and `multi_book_bpe*` files.
