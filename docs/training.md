# Training

`configs/default.json` is the portable CPU character-model configuration. `configs/alice_bpe.json` is a larger optional subword experiment. The training split is a contiguous prefix, validation follows it, and test is the final segment; windows are built after splitting, preventing overlap across boundaries. The configured tokenizer is fitted only to training text. Validation loss is sampled during training, and the checkpoint contains the weights from the step with lowest measured validation loss. Training uses AdamW, gradient clipping, fixed learning rate, and reproducible Python/PyTorch seeds.

`python scripts/train.py --config configs/default.json` trains the configured steps. `--steps N` bounds a run. Checkpoint state, tokenizer, config, measured history CSV, and (when there are at least three evaluation points) a loss plot are saved under the configured output directory. Checkpoint metadata records the best validation step, loss, parameter count, and run duration. Optimizer state resume is not implemented. PyTorch checkpoint loading should be limited to files you trust.
