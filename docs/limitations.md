# Limitations

The bundled corpus is a tiny, purpose-written educational fixture, not a licensed representative natural-language benchmark. A character tokenizer has a small transparent vocabulary but long sequences. CPU training is slow and the model has very low capacity. Contiguous splits can make evaluation sensitive to corpus ordering. Training selects the checkpoint with lowest sampled validation loss and writes a history CSV and loss plot when enough evaluation points exist; optimizer state resume and a broader qualitative evaluation report are not implemented. The 300-step fixture run's test loss (3.0402) remained worse than the smoothed bigram baseline (2.8374), and its generated text was incoherent. Generated text can repeat, memorize, or state falsehoods. This is an educational implementation, not a production assistant.
